# Tuya wizard output

Raw output from `python -m tinytuya wizard` and `python -m tinytuya scan`.

Nothing here is read at runtime - `local_secrets.py` holds everything the
CLI needs. These files are kept only as a record of what the wizard
returned, and are gitignored because they contain the local key and API
credentials.

Safe to delete. Re-created by re-running the wizard.
